# BL-BR-03 · uBlock Origin or Brave shields in every browser profile

**Why:** Malicious ads ("malvertising") push fake download pages for popular tools to the top of search results. A content blocker removes them, and with them a common way stealers get installed.

**Real attack:** In September 2023 Malwarebytes found Google search ads for the TradingView charting app that led to a look-alike download site; its Mac button delivered the AMOS stealer. ([source](https://www.malwarebytes.com/blog/threat-intel/2023/09/atomic-macos-stealer-delivered-via-malvertising))

**Check it yourself:** the uBlock Origin icon is in each browser's toolbar (in Brave, the shields are built in).

**How to fix:** install uBlock Origin (Firefox) or uBlock Origin Lite (Chrome and Edge) in each profile the agent names, or use Brave with shields on.

**What the agent is doing:** listing each profile's installed extensions by id and name.
