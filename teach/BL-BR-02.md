# BL-BR-02 · A password manager extension in every browser profile (1Password, Bitwarden or iCloud Passwords)

**Why:** A password manager's extension fills a password only on the site it belongs to, so a look-alike phishing site gets nothing, and you never need the browser's own password store.

**Real attack:** Phishing pages copy real login pages exactly. 1Password says its autofill only works on the exact domains your logins are saved for, so on a look-alike site it offers nothing, which is your warning. ([source](https://support.1password.com/kb/202508))

**Check it yourself:** your password manager's icon is in each browser's toolbar, in every profile.

**How to fix:** install your password manager's extension from your browser's extension store in each profile the agent names, and sign in: 1Password (paid), Bitwarden (free), or iCloud Passwords if you use Apple's Passwords app (Chrome, Edge and Firefox). Safari needs no extension. If you use another password manager, tell the agent to record it as your decision (ACCEPTED) with its name as the reason.

**What the agent is doing:** listing each profile's turned-on extensions by id and name.
