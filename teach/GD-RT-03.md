# GD-RT-03 · No live malware process, C2 connection or known backdoor file

**Why:** The other checks look at settings and files. This one looks for malware that is already running: a hidden loader process, a connection to an attacker's server, or a backdoor left behind.

**Real attack:** In November 2026 hijacked npm packages started `node -i` in the background, with no terminal, and piped their loader into it. On 29 October 2026 a trojanized Claude Code extension added a LaunchAgent named `com.apple.sysmond`, dropped a script at `~/.config/.smt`, and added its own SSH key, labelled `svc-telemetry`, to `~/.ssh/authorized_keys` ([source](https://www.sonatype.com/blog/polinrider-loader-reappears-in-hijacked-npm-packages), [source](https://cursor.com/blog/claude-code-extension-security-notice)). The same loader family later patched VS Code's, Cursor's and Discord's own start-up files, so opening the app ran it again ([source](https://blog.greenflagged.dev/posts/2026-11-03-adminide-stack-eth-dead-drop/)).

**Check it yourself:** `ps -axo pid,ppid,tty,command | grep -E 'node|python|ssh'` (`??` in the TTY column means no terminal); `lsof -nP -iTCP -sTCP:ESTABLISHED`; `ls -la ~/Library/LaunchAgents ~/.config/.smt*`; `grep svc-telemetry ~/.ssh/authorized_keys`; `crontab -l`; `codesign --verify --deep --strict "/Applications/Visual Studio Code.app"` (an app that fails it has been changed since its maker signed it).

**How to fix:** don't try to clean it up yourself, and don't type passwords until it's dealt with: type `/if-red` and follow it. A note on a PASS (a short inline script, a temp folder that exists, a file name malware also uses) is worth a look but isn't malware on its own.

**What the agent is doing:** listing processes (name, parent, terminal, age, and for node and python their working folder; command lines only to recognise a loader or a reverse SSH tunnel, never shown), your own network connections, known backdoor file names, your shell and npm start-up files, your global git hooks, your crontab, LaunchAgents and LaunchDaemons, the start-up files of VS Code, Cursor, Antigravity, GitHub Desktop and Discord, and the temp folders loaders stage in. It reports file names and line numbers, never the lines themselves. Nothing changes.
